# Checkpoint — 2026-09-23: hook v10 executable provenance (uncommitted draft)

Status: implemented and tested; **left uncommitted on purpose**. The baseline commit before this work is `be3f8a9` ("Baseline before hook v10: v9 visible-SVG provenance, painting mode, Claude Agent SDK provider"). Everything below is working-tree only.

## Motivation

Hook v9 stated a causal rule in `resources/svg-composition-context.md` ("deleting all audible marks must leave the renderer with no composition to perform") but `resources/check_output.py` could only approximate it from attribute names. A valid composition using `data-lane` was flagged "no visible semantic event marks" and burned the single automatic repair turn on output whose audio was bit-identical. The same ~1,300 words of fixed rules were re-sent as user-message text every turn, and the contract itself was long prose that the checker could not enforce.

## Changes

- **`resources/silence_check.py` (new)** — the executable silence test. Parses the SVG (rejects DTD/ENTITY), collects `data-audible` elements, requires them drawable and visible, statically rejects a `render.py` that hardcodes the absolute delivery path, copies the version directory to a `tempfile.TemporaryDirectory()` without the delivered audio, deletes every `data-audible` element from its copy, and runs the renderer in bubblewrap (`--ro-bind / /`, writable copy, `--dev`, `--proc`, `--tmpfs /tmp`, `--unshare-net`, `--die-with-parent`, `--chdir`, `MPLCONFIGDIR` in the copy, `sys.executable`, 180 s). Outcomes: non-zero exit, missing output, non-finite samples and peak > 1e-4 are issues; timeout and a missing `/usr/bin/bwrap` are warnings (never an unsandboxed fallback); a pass records `{marks, peak, seconds, ran}`. The real delivery directory is only ever read.
- **`resources/check_output.py`** — for `workflow=generation`, `visibleEventMarks` now counts visible `data-audible` elements and the "no visible semantic event marks" issue becomes the `data-audible` message. Every other check (scripts/handlers, external hrefs, generation metadata, image warning, viewBox, custom `<event>` tags, renderer reads score.svg/geometry, audio stats) is unchanged, and the file still never executes generated code. The old attribute-name logic remains for `reference`, where packed spectral SVGs have no `data-audible`.
- **`server/hooks.mjs`** — `afterTurn` runs `silence_check.py` after `check_output.py` when `mode==='sound' && workflow==='generation'` (same interpreter, 200 s cap), merges issues/warnings and sets `report.silence`; a script-level failure becomes a warning. `beforeTurn` takes `provider`, drops `workbench-context.md`/`output-context.md`, appends `research-codex.md` when `provider !== 'claude'`, and reports `version: 10` (painting audit unchanged).
- **`server/index.mjs`** — sound system prompt is `composer.md + workbench-context.md + output-context.md`, built once at startup; `beforeTurn` gets `provider: v.provider`; SHA-256 `systemPromptHash`/`contextHash` stored on `v.contextHook` and `system-prompt.md` written beside `context.md`; one sentence added to the sound repair text about `data-audible` and finite silence.
- **Prompts** — `svg-composition-context.md` rewritten to 101 words (≤120 target) covering `data-audible`, attribute controls, no score in metadata/base64/hidden/render.py, builder scripts allowed, and the sandboxed empty-score test with normalisation guard and relative outputs. `composer.md`: "metadata for parameters" → "attributes on marks for parameters", plus one `data-audible` sentence. `output-context.md`: dropped the paragraph the enforced test now covers, delivery/manifest rules kept, net shorter. `research-context.md` made provider-neutral; the `functions.exec` / `tools.web__run` wrapper example moved to **`resources/research-codex.md`**, injected only for non-Claude providers. No musical or creative advice was added anywhere.

## Limitations

- The silence test proves provenance of sound, not musical quality, and not that every audible detail is recoverable from geometry. A timeout (180 s) is inconclusive; a renderer that reads the original directory through the read-only `/` bind could theoretically copy its own delivered audio, which would fail as "Sound remains…" rather than pass.
- Hot paths are unexercised outside tests: no live model turn ran under hook v10, so the shortened contract and the system-prompt move have not been judged by a real composer turn. Prompt hashes exist for exactly that future comparison.
- `bwrap` availability was verified on this machine (`/usr/bin/bwrap`, user namespaces working); the skip-warning path was not exercised here because bubblewrap is installed.
- Static checks can still reject an honest but unusual SVG (e.g. audible `<text>`); such a rejection costs one bounded repair turn.
- The silence test proves "no audible marks -> silence", not that every sound comes from the marks: a renderer that plays Python-held material whenever any mark exists would pass.
- `bwrap` binds `/` read-only, so user sockets (e.g. D-Bus) remain reachable from the renderer; accepted for personal local use, tighten binds before any shared deployment.
