# Painting working context

Make the requested visual artifact now. Translate intent into composition before adding detail: decide the focal structure, large value masses, palette logic, depth and mark language. Richness comes from purposeful variation at several scales, not random noise or an indiscriminate number of paths.

The model may write a temporary Python builder to author dense SVG geometry. The final contract stays causal: painting.svg contains the visible construction and render.py interprets it. Renderer algorithms may turn SVG marks into textured brushwork, but must not contain an independent hardcoded composition. Preserve deterministic seeds in SVG or attributes.

For source images, use analysis.json as measured evidence and inspect source, palette.svg and edges.png when tools permit. Use measurements to anchor proportions, value and palette; they do not replace visual judgment. No online research is required unless the request itself needs outside facts or a named artwork.
